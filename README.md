# GoSense

Приложение с открытым исходным кодом для мониторинга параметров окружающей среды, которое регистрирует температуру и относительную влажность с Bluetooth BLE-устройств, а также атмосферное давление с вашего телефона (если поддерживается).

---

## Возможности

### Панель управления
Отображает текущие показания с подключённого датчика в реальном времени:
- Температура
- Относительная влажность
- Точка росы
- Индекс жары
- Гумидекс
- Атмосферное давление (если в устройстве есть барометр)

Переключение единиц измерения (Цельсий/Фаренгейт, мбар/гПа/кПа/Psi) прямо с панели.

### Зона комфорта
Визуализация текущих условий на графике «температура — влажность»:
- Границы зоны комфорта (летняя и зимняя) на основе рекомендаций Sensirion SmartGadget
- Точка текущих показаний, окрашенная в цвет устройства
- Подписи зон риска: ревматические боли, тепловой удар, обезвоживание, проблемы с дыханием

### История
Построение графиков измерений за выбранный интервал:
- 10 минут, 1 час, 3, 6, 12, 24, 48 часов, 7 и 14 дней
- Температура, относительная влажность, атмосферное давление
- Автоматический масштаб по данным, усреднение точек
- Экспорт и импорт базы данных в формате `.csv.gz`

### Устройства
Управление BLE-датчиками:
- Сканирование и сопряжение новых устройств
- Список сопряжённых устройств с отображением уровня сигнала и заряда батареи
- Выбор основного устройства для отображения данных
- Назначение цвета графика для каждого устройства
- Автоподключение при запуске и автопереподключение при обрыве связи

### Настройки
- Имперская/метрическая система единиц
- Зимний/летний сезон для зоны комфорта
- Единицы атмосферного давления
- Интервал обновления графика
- Срок хранения данных в базе
- Очистка базы данных
- Отключение оптимизации батареи
- Режим сканирования BLE (низкое энергопотребление / низкая задержка)
- Порядок сортировки при сканировании

### Уведомления
- Постоянное уведомление с текущими показаниями и статусом подключения
- Уведомление о разрыве связи с устройством

## Примечания

- Протестировано с BTH01 и TH05F с прошивкой PVVX, совместимой с BTHome.
- В настоящее время поддерживается только одно устройство одновременно.
- Экран «Зона комфорта» заимствован из приложения Sensiron SmartGadget для использования в помещении.
